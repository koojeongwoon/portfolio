# 🧾 CHANGELOG

## [1.2.0] - 2025-10-23
### ✨ 주요 변경사항

#### 🚫 Jina 서비스 삭제
- 유튜브를 제외한 URL 요약에 사용되던 서드파티 **Jina AI** 서비스를 제거했습니다.  
- 모든 URL 요약 로직을 **Gemini API** 기반으로 통합했습니다.  
- URL 분리용 변수를 제거하여 **코드 구조가 단순화**되었습니다.

#### ⚙️ 프롬프트 요청 방식 개선
- **변경 전:** 사용자 프롬프트에 시스템 프롬프트 내용을 함께 삽입  
- **변경 후:** 사용자 프롬프트와 시스템 프롬프트를 **명확히 분리하여 전달**  
- 프롬프트 구조 개선으로 **가독성 및 유지보수성 향상**

#### 🌐 API Tool 호출 기능 추가
- **Google Search Tool**을 새로 도입했습니다.  
- 요약 시 **최신 정보 및 맥락 반영**이 가능해졌습니다.  
- **유튜브 업로드일**, **기사 작성일** 등 메타데이터를 포함할 수 있도록 개선했습니다.
